# TrueBalance (formerly OfflineCPA)

Welcome to TrueBalance! This is a privacy-first, completely local bookkeeping and transaction management system designed for individuals and small businesses who want full control over their financial data. 

## Why TrueBalance?
Many modern bookkeeping solutions require you to upload your sensitive bank statements and financial data to the cloud. TrueBalance is built differently. It provides a complete environment to safely categorize, audit, and manage your financial transactions locally. 

**Your data never leaves your machine.**

## Project Structure
- `OfflineCPA/`: This directory contains the main web application and API that powers the bookkeeping interface.

## Getting Started
To get the application up and running on your local machine:
1. Open your terminal and navigate to the `OfflineCPA` directory.
2. Follow the setup instructions provided inside that directory to start the local server and web interface.

*Note: Because this project is designed for strict privacy, all databases and files are stored locally by design.*
